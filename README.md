# Student Performance Analyzer 📊

A beginner Python project that analyzes student marks and generates a performance report.

## Features

- Accepts marks for five subjects
- Calculates total marks
- Calculates percentage
- Assigns grades
- Identifies the highest-scoring subject
- Identifies the lowest-scoring subject
- Displays a performance message

## Technologies Used

- Python
- Google Colab
- Matplotlib (for data visualization)

## Sample Output

Total Marks: 391

Percentage: 78.2%

Grade: B

Highest Subject: Maths

Lowest Subject: Physics

Good performance!
